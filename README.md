# TowerRadar 0.27.2 — сохранение выбранной подложки

- Выбранные пользователем **Яндекс Карты, MapTiler, OSM и другие подложки не подменяются автоматически** при входе в настройки офлайн-областей, при выборе области, сохранении региона и его просмотре.

- Полные офлайн-пакеты **OpenFreeMap** остаются доступны при явном выборе OpenFreeMap в списке подложек. Загрузку выполняет OfflineAreaManager, не меняя текущую подложку приложения.
- Исправлена гонка: запоздалая проверка автоматического OSM-сервера больше не может перезаписать ручной выбор карты. Для Яндекс Tiles / MapTiler карта восстанавливается из сохранённого выбора даже при временной ошибке проверки ключа.
- Исправлено отображение переносов строк в диагностике кеша.

# TowerRadar 0.24.0 — обновления интерфейса и работа с вышками

**Настройки:** тематические разделы «Оформление и экран», «Карты и офлайн», «Вышки и рельеф», «Геопозиция и сеть», «Компас и наведение», «Обновления». Действующая тема Khaki Modern сохранена. Кнопка «Добавить вышку вручную» находится также в раскрытом меню «Подробнее».

**Пользовательские вышки:** форма для названия, координат, оператора, технологий, высоты конструкции, дополнительного оборудования, примечания и одной фотографии из файлов телефона. Фото уменьшается и хранится в приватном каталоге приложения. Запись доступна только на устройстве, не отправляется в OSM. Её можно найти и удалить в «Настройки → Вышки и рельеф → Пользовательские вышки». Записи не очищаются вместе с публичной базой/кешем карт. Уничтожение данных приложения Android удалит и приватные записи.

**Карточка выбранной вышки:** две компактные кнопки «Профиль высот» и «Зона покрытия». Зона покрытия — круг выбранного пользователем условного радиуса от 500 м до 10 км, НЕ прогноз радиосигнала. Оператор из тега network OSM отображается как предположение, а не как подтверждённый факт. Если данных нет, оператор прямо помечен как неопределённый. Для своей вышки доступны фотография и удаление.

**Профиль высот:** реальная отметка рельефа из DEM; при известной высоте конструкции — пунктир до её верха, который не является высотой самой антенны. При отсутствии высоты используется расчётный сценарий 20, 25, 30 либо 50 метров, с обязательной пометкой об условности. 30 м — модельное значение макросотовых станций в отчётах ITU-R, НЕ средняя высота всех реальных мачт: https://www.itu.int/dms_pub/itu-r/opb/rep/R-REP-M.2039-4-2025-PDF-E.pdf . Нельзя считать это достоверной линией радиовидимости без данных о высоте антенн, зданиях и зоне Френеля.

**Карты и офлайн:** в темной теме тайлы Яндекс Tiles приглушаются стандартными средствами MapLibre (неофициальное затемнение растровых тайлов; не касается спутника и гибрида Yandex JS WebView). Управление уже просмотренным кешем сохраняется. Массовая офлайн-загрузка областей РФ/Украины пока НЕ реализована и не запускается: она нарушала бы условия публичных серверов OSM; приложение объясняет ограничения и показывает общее количество уже сохранённых вышек.

**Компас:** отдельный раздел с текущей точностью датчика и пошаговой инструкцией калибровки «восьмёркой». Android выполняет аппаратную калибровку самостоятельно.

**Обновления по сети:** только после ручного нажатия приложение проверяет опубликованные GitHub Releases. Стабильные и тестовые версии отделены. Если обнаружен более новый APK, он скачивается системным Android DownloadManager, пользователь сам подтверждает его установку; скрытого обновления, писем и постоянного мониторинга нет. Новые APK подписаны прежним сертификатом. GitHub Actions выполняет unit-тесты, lint и проверку подписи перед публикацией тестового релиза; workflow Promote tested APK to stable позволяет вручную перевести проверенный prerelease в стабильный без пересборки и смены подписи.

**Сохранено из v0.23.0:** расположение индикатора обновления без перекрытий, возвращение вниз при закрытии панели/карточки, профиль высот от GPS или ручной точки, сброс устаревшего выбранного объекта после реального изменения геопозиции.

# TowerRadar

An independent Android application for showing nearby telecommunications masts and potentially mobile-network installations on a live map.

**Version:** 0.4.0 (prototype). **Language:** Russian. **Platform:** Android 8.0+.

## Features

- GPS-based search with user location marker and updates while the app is open.
- MapLibre map with a built-in raster style, availability probing and manual map provider switching: OSM France, OpenStreetMap, OSM Deutschland, and OSM HOT.
- Real-time phone azimuth from the rotation vector sensor with magnetic declination correction, displayed as an arrow on the GPS marker.
- Optional OpenCellID key entry for estimated positions of logical radio cells near the center, not physical masts.
- Expanded Overpass API query with mast/antenna/operator tags, plus server failover: VK Maps Overpass, Private.coffee, and FOSSGIS.
- Radius selector: 1, 3, 5, 10, 20, 50 km.
- Filtering by reported operator, map pin detail panel, OSM source link.
- Blue markers indicate OSM tags mentioning mobile communication; orange markers indicate unconfirmed telecom structures.
- Cached result for recent searches, manual refresh, network error messages.
- No location history collection and no background location tracking.

**Data limitations:** OpenStreetMap is crowd-sourced and incomplete. A mapped mast is not necessarily a mobile cellular base station. No frequency, live serving-cell identity, precise radio cell estimate, or operator ownership is inferred when the tags do not specify it. An empty region does not prove there are no towers. On manual refresh, approximate search coordinates are sent to the public Overpass endpoint.

## Development

Open the repository in Android Studio with JDK 17. Android Gradle Plugin 8.11.1, Gradle 8.13, Kotlin 2.2.21, compileSdk 35, MapLibre Android 13.7.1.

The GitHub Actions workflow on push to main runs JVM unit tests, Android lint, debug APK assembly, signature verification and checksum generation. The resulting **TowerRadar-debug-APK** is available under the successful run's **Artifacts** section.

Debug APKs are signed with GitHub Actions' temporary debug signing key. Do **not** rely on the signature staying identical across builds or devices; Android app upgrades may require uninstalling the previous debug build. A stable, user-owned release keystore is a later milestone and must never be checked into the repository.

### v0.2.0 limitations

Map tiles require an available external tile server; on some networks all public servers may be blocked. The app switches among independent sources, but no online-only solution can guarantee availability without VPN. A logical cell position from OpenCellID is not proof of a physical cellular tower. ### Ограничения и проверка

Для чтения точной обслуживающей соты требуются доступ к точной геопозиции и разрешение READ_PHONE_STATE. Android и модем могут скрывать Cell ID и некоторые метрики; в режиме 5G NSA обслуживающая сота может отображаться как LTE. Системное местоположение, Wi-Fi и спутники могут давать разную погрешность в зависимости от условий. Частота радиообновлений зависит от ОС. Доступ к геопозиции и радио используется только пока приложение открыто.

Без личного ключа OpenCellID координаты соты не запрашиваются с сервера. Поиск вышек по Overpass передаёт выбранные координаты на сервер данных. Все личные API-ключи сохраняются только локально на устройстве; ограничения использования и тарифы определяют поставщики. Ключи пока хранятся в Android SharedPreferences без отдельного аппаратного шифрования — используйте ключи, ограниченные у поставщика.

GitHub Actions проверяет unit-тесты, Android Lint, сборку и криптографическую подпись debug APK. Геопозицию, показания реального модема и визуальный контраст экранов необходимо дополнительно проверять на пользовательском телефоне. Debug APK разных сборок может подписываться разными временными ключами и требовать удаления старой версии.

**Лицензия Яндекса:** требуется официальное брендирование Tiles API, включая логотип по текущим правилам. Перед публичным или коммерческим распространением проверьте условия Яндекса и других поставщиков карт.

## TowerRadar v0.8.0 — Яндекс в HiDPI и кеш загруженных карт

Событие полностью потребляется, без выбора вышки и случайного перемещения карты. Тапы внутри панели продолжают выполнять свои действия, свайп вниз и кнопка «Свернуть» сохранены. Назад также сворачивает развернутую панель.
- **Яндекс: скрытие лишней кнопки.** Кнопка «Подключить Яндекс Карты» показывается только когда ключ отсутствует. Сохранённый ключ предлагает «Проверить подключение», при проверке отображается ожидание, при ошибке «Исправить подключение». После успешного ответа Tiles API кнопка **полностью скрывается (View.GONE)**, соседние элементы занимают освободившееся место. Управление ключом остаётся в разделе «Подключения API».
- **Тесты.** Добавлены unit-тесты проверки касания внутри/снаружи панели, исключений для полноэкранного режима и режима перекрестия, а также всех состояний кнопки Яндекса.
- **Версия 0.9.0 — pre-release.** Перед переводом в стабильную 1.0.0 требуется отдельное согласие пользователя.

## TowerRadar v0.10.0 — постоянная подпись, модем и соседние соты

- **Постоянная APK-подпись:** GitHub Actions собирает неподписанный release APK, выравнивает его zipalign, подписывает единственным RSA4096 сертификатом из четырёх `TOWERRADAR_*` GitHub Actions Secrets и проверяет v1/v2/v3 подписи. Отпечаток SHA-256 сертификата внутри APK проверяется по сертификату исходного хранилища, а SHA-256 APK — перед публикацией. Если нет секретов, пароля, или подпись не совпала, новая версия **не публикуется**. Файл `.jks` и пароли отсутствуют в репозитории и релизах.
- **Важное однократное ограничение:** старые v0.9.0 и ранее были подписаны debug-сертификатом. Android не позволяет установить сборку с новым сертификатом как обновление старой — прежде сохраните установленные ключи API и пользовательские настройки и только потом, если потребуется, удалите старое приложение. Из-за `allowBackup=false` старая версия не поддерживает автоматический экспорт настроек. Начиная с первой постоянно подписанной APK следующие версии с тем же applicationId, сертификатом и более высоким versionCode смогут устанавливаться поверх неё.
- **Мониторинг без GPS:** уровень dBm, RSRP, RSRQ, SINR, название оператора/поколение сети и 5 делений получаются через отдельный `SignalStrength`-канал при наличии доступа к телефону. Доступ к Cell ID и другим идентификаторам остаётся ограничен Android при отключённой системной геолокации или отсутствии разрешения `ACCESS_FINE_LOCATION`. Нет догадок о том, к какой вышке подключён телефон, если Cell ID недоступен.
- **Сканер соседних сот:** Android `CellInfo` показывает полученные от модема соседние радиосоты (когда доступ разрешён) и параметры PCI, EARFCN/NRARFCN, диапазоны B/n, Timing Advance, ширину канала, RSRP/RSRQ/SINR. Модем не обязан возвращать соседние соты на каждом устройстве; 5G NSA может сообщать LTE.
- **Источники и достоверность:** точный поиск отдельной радиосоты по MCC/MNC/TAC/Cell ID/radio через OpenCellID выполняется только по запросу пользователя; карта различает бирюзовым маркером приближённые позиции OpenCellID и физические мачты OSM. В карточке показываются количество наблюдений, примерный радиус и параметры антенны из OSM, если они есть. Ни ближайшая мачта, ни запись в реестре **не считаются автоматическим подтверждением активной соты**.
- **Официальные реестры:** ссылки на официальные национальные картографические реестры Нидерландов, Франции и Германии открываются в браузере. Их массивные выгрузки пока не импортируются автоматически; возможность интеграции данных зависит от доступности API/лицензии. Неофициальный парсинг CellMapper не используется.
- **Защищённые настройки:** `Настройки → Резервная копия` экспортирует и импортирует API-ключи и выбранные параметры только в пользовательский зашифрованный файл AES-256-GCM с PBKDF2 и отдельным паролем (не менее 12 символов). Файл .jks в такой бэкап не входит; этот экспорт появился только в 0.10.0 и не переносит автоматически старые настройки v0.9.0.
- **Статус:** v0.10.0 — **Pre-release**. Версию 1.0.0 стабильной считать и публиковать без отдельного согласия пользователя нельзя.

Android unit-тесты, Lint и проверка цифровой подписи проходят в GitHub Actions. Фактическая доступность радиопараметров на смартфоне, операторе и в конкретном режиме энергосбережения проверяется только на реальном устройстве.

## TowerRadar v0.12.0 — компактное направление и точное наведение

- Вместо встроенного круглого MapLibre-компаса используется **буква N и тонкая стрелка** над правыми кнопками карты, без видимого фона и окружности. Стрелка показывает север относительно поворота **карты**, а не азимут телефона; обновляется по мере перемещения камеры. Поворот телефона для конуса луча продолжает определяться отдельно датчиком.
- При ручной геопозиции изображаются **четыре тонких тёмно-оливковых уголка с контрастным контуром и точкой** (в ночной теме цвета адаптируются). Координаты шестизначной точности обновляются при каждом событии перемещения/масштабирования камеры, не ожидая её остановки. Кнопка «Установить точку» сохраняет координаты из самого центра на момент нажатия; отмена возвращает камеру, не меняя сохранённое положение.
- Вместо затемняющего модального диалога используется **компактная несворачивающая карту панель** над нижним индикатором сети, оставляющая доступными карту и её жесты вне области ползунков. Яркость пунктирного луча и сектора регулируется независимо от 0 до 100%, значения применяются сразу и сохраняются. Закрытие не сбрасывает значения.
- v0.12.0 публикуется как **Pre-release** и подписывается постоянным сертификатом TowerRadar; продолжает цепочку обновлений с v0.10.0 и v0.11.0 при совпадающей подписи.

## TowerRadar v0.13.0 — сохранение последнего обзора и landscape

- При выходе сохраняются центр карты, масштаб, угол поворота и наклон, **отдельно от выбранной геопозиции GPS/вручную**. Повторный запуск восстанавливает последний просмотренный регион до установки стиля; GPS продолжает обновлять данные местоположения и сигнал, но не перемещает карту при обычном открытии. Для возврата есть кнопка позиционирования.
- Запоминается источник тайлов, в том числе ранее автоматически выбранный провайдер OSM. Выбранные Яндекс/2ГИС тайлы с действительным ключом запускаются без промежуточного OSM. Ошибка проверки сервера не стирает выбор. Google Map Tiles API требует нового сеанса на каждом запуске, при отсутствии API остаётся ограничение провайдера.
- MapLibre ambient cache используется для уже просмотренных OSM/Яндекс участков с лимитом 100/250/500 МБ; Яндекс автоматически очищается не позднее 29 дней. Google и 2ГИС не сохраняются на диск из-за условий провайдеров. В настройках кеша отображаются политика источника, предел, последняя очистка и число сетевых запросов за сеанс. Это **не** точный размер базы тайлов или гарантия офлайн-покрытия.
- Поворот в альбомную ориентацию не пересоздаёт Activity/MapView. Вместо высокого нижнего листа раскрытая панель расположена справа (~29% ширины); панель настройки направления и элементы выбора геопозиции также не закрывают центр карты. Переходы и UI элементов анимируются без пересоздания карты. Элементы учитывают системные вырезы и навигацию.
- Указатель N/стрелка по умолчанию использует магнитно-ориентированный Rotation Vector и поправку геомагнитного склонения при наличии GPS, обновляется при повороте телефона и экрана. По нажатию переключается между компасом телефона и севером карты. При отсутствии датчика используется север карты.
- Сектор обзора отделён от длинного пунктирного луча: длина сектора регулируется от 10 до 70% от длины луча, по умолчанию 30%. Яркость независима.
- **v0.13.0 — Pre-release**, распространяется только APK, подписанный постоянным сертификатом TowerRadar. Перед выпуском 1.0.0 stable требуется отдельное одобрение пользователя.


## TowerRadar 0.26.0 — offline areas and safe APK updates

- **Maps > Offline areas and cache > Save area around map center**: choose a 2/5/10/20 km radius and a supported maximum zoom. A saved area requests all zoom levels from z6 through the selected zoom (not just the currently visible screenshot).
- The only prefetch-enabled built-in basemap is **OpenFreeMap** (vector style at `https://tiles.openfreemap.org/styles/liberty`). OpenStreetMap Foundation, Yandex, and other providers are not used for bulk downloading. Bounds and zoom must fit the per-download limit. Actual download progress, completeness, and limits are checked by MapLibre; unfinished areas remain incomplete.
- The same area saves **Mapzen Terrarium** elevation tiles for local terrain profiles. A complete saved DEM allows calculation of new lines between any two points covered by the area, without internet. A previously generated exact profile is also retained after 30 days. Incomplete or never-downloaded areas cannot provide fabricated heights.
- **My saved areas** shows map/terrain availability; use it to resume, pause, visit or delete the area. Base station records are held in the existing separate SQLite database. Deleting an area does not delete saved towers.
- The standard map always has the fixed four-ray reticle in the exact center. The upper coordinates are the map center, *not* the GPS fix. Tap them to copy. Tap the coordinate row in any tower detail to copy that tower's location.
- The automatic base station refresh is attempted at most once per app launch, with a progress result and notification when Android permission is granted. Further refreshes require user action.
- **Settings > Updates** checks stable and prerelease GitHub Releases. It can download the APK into the application's Downloads area, display progress, verify asset SHA-256, package name, increasing Android version code and the installed signer, then open the system installer. Android must still approve installation. Installed data is not cleared.

Offline limitations: map labels and zoom details cannot exceed what the source style and tiles actually provide. MapLibre's `isComplete` status is the map download completion signal. A completed map with an incomplete DEM must not be described as a complete combined offline pack. Downloading an area does not grant rights to bulk-download other map providers.

See https://openfreemap.org/tos/ and https://operations.osmfoundation.org/policies/tiles/.
